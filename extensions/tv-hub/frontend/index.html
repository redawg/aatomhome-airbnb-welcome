          Settings guide — what everything does

          Two layers of welcome content

          Welcome text is stored in two layers. TVs always show the live welcome (defaults + any per-stay overrides). You do not need to redeploy the launcher APK when you edit text — TVs load content live from /guest/.

          • Property defaults — baseline WiFi, rules, tips, and branding. Set once; reused for every stay. Save with Save property defaults.
          • Live welcome — what guests see right now. Can differ from defaults (guest name, one-off changes). Save with Save welcome.

          Welcome form fields

          Logo
          Property image at the top of the TV welcome screen. Upload saves to defaults immediately.
          Background image
          Full-screen photo behind the welcome content on TV. Upload saves to property defaults.
          Guest name
          Per-stay only. When set, the TV title becomes “Welcome, [name]!” Check in saves the name and records an active stay. Check out clears it between guests.
          Check-in / Check-out dates
          Set the guest’s stay window. The TV weather card forecasts these dates and recommends the best days for hiking and hot springs.
          Welcome title / Subtitle
          Headline and tagline when no guest name is set. With a guest name, title is auto-generated.
          WiFi network & password
          Shown on TV with a QR code guests scan with their phone. Update here when the network changes.
          Checkout time
          Displayed in the header pill on the welcome screen.
          Digital guidebook URL
          Optional link encoded as a QR on TV (house manual, Notion page, etc.).
          Thermostat, Parking, Trash
          Short property-info lines in the info cards on the welcome screen.
          Weather location / lat / lon
          Outdoor forecast on TV. Set coordinates and stay dates at check-in — the welcome screen shows daily highs/lows plus best days for hiking and hot springs.
          House rules & Local tips
          Multi-line text in scrollable cards on the TV welcome page.
          TV instructions
          Helper text on the welcome screen (how to use Home, streaming, etc.).
          Emergency contact & phone
          Shown in the help section on the welcome screen.

          Save & guest actions

          Save welcome
          Saves the live welcome TVs show now. Only fields that differ from defaults are stored as overrides. Preview updates immediately.
          Save property defaults
          Saves the form as the property template for future stays (everything except guest name). Does not clear an active guest name.
          Load defaults
          Fills the form from saved defaults. Keeps the current guest name field unchanged.
          Reset live to defaults
          Clears all per-stay overrides (including guest name) so TVs show property defaults only.
          Apply welcome to TV
          Saves welcome, then opens the welcome screen on the selected connected TV. Does not change launcher install state.
          Check in / Check out
          Check in — set guest name + active stay record. Check out — clear guest name and end the stay (same as reset for the name).

          TV setup buttons

          Provision New TV
          Full first-time setup on the selected TV: ADB reboot helper, hide debug UI, install guest launcher, sync streaming apps, open welcome. Use on a newly registered TV.
          Setup this TV
          On Main TV, this becomes Update all TVs from Main TV — saves welcome, updates the launcher, then rolls out to BED 2, BED 3, and any other online property TVs automatically. On other TVs, it only updates that one unit.
          Update all property TVs
          Saves welcome, then updates the launcher on every online property TV (Main TV first). Use this when Main TV is offline or you want a full-property push without selecting a TV.
          Restore Google TV
          Re-enables stock Google TV launcher on the selected TV and removes guest-launcher lockdown. Use to undo guest mode.
          ADB Reboot Helper
          Installs a helper so wireless debugging survives reboots (main profile). Needed for hub to stay connected after power cycles.
          Apps only mode
          Google TV setting that hides personalized recommendations on the home screen. The hub can request it via ADB; if that fails, enable manually under Settings → Accounts & Sign In → your profile.

          After deploy, press Home on the TV and choose Guest Welcome → Always if prompted. Google TV blocks setting default home over ADB alone.

          If welcome does not return after closing Netflix or other apps: Settings → Accessibility → Guest Welcome and enable the service. Deploy tries to turn this on automatically; some TVs require manual approval.

          Streaming apps

          Allowed streaming apps
          Checkboxes control which apps appear on the TV welcome screen and which get installed/enabled on the main profile. Click Apply to TV on the selected TV to push changes.
          Set as Source
          Marks the selected TV as the template. Its installed streaming apps are copied when you mirror.
          Mirror to All TVs
          Copies streaming apps from the source TV to all other connected TVs.
          Clear streaming logins
          Signs out of Netflix, Disney+, etc. on the TV (or all TVs). Guests sign in with their own accounts. Does not uninstall apps.

          Remote updates (no on-site visit needed)

          • Save welcome — hub automatically opens the updated screen on every online property TV within a few seconds.
          • TV reconnects — after a reboot or power cycle, the hub launches the welcome app when the TV comes back online.
          • While a TV is on — the welcome page checks the hub every 2 minutes and reloads when content or styling changes.
          • Launcher APK updates — use Update all property TVs after rebuilding the APK (hub cannot push a new APK without ADB).

          TV provisioning — two paths

          Path 1 needs no dev options. Path 2 uses ADB for hub-driven install and lockdown.

          1. TV main profile: sign in with property guest Google account

          Path 2 — Hub via ADB
          1. TV main profile: sign in with property guest Google account
          2. TV: Developer options → wireless/network debugging
          3. Register → Pair → Connect → Push welcome app
          4. Apply streaming apps · clear logins between stays
